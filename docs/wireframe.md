# 와이어프레임 (Wireframe) - 마이링크(My-Link)

## 1. 퍼블릭 프로필 페이지 (방문자 & 소유자 공통 화면)
마이링크의 핵심인 프로필 페이지입니다. 모바일 환경을 우선적으로 고려한 깔끔한 단일 컬럼 레이아웃(shadcn/ui 기반)입니다. 소유자가 로그인한 상태일 경우, 텍스트를 직접 클릭하여 인라인 편집이 활성화됩니다.

### 1.1 ASCII 아트 기반 화면 구조
```text
+---------------------------------------------------------+
|                                  [공유] [로그아웃/설정] |
|                                                         |
|           +---------------------------------+           |
|           |             홍길동              |           | <- username (클릭 시 인라인 수정)
|           +---------------------------------+           |
|           | 프론트엔드 개발자입니다.        |           | <- Bio 소개글 (클릭 시 인라인 수정)
|           | 방문해주셔서 감사합니다.        |           |
|           +---------------------------------+           |
|                                                         |
|  +---------------------------------------------------+  |
|  | [+] 새 링크 추가                                  |  | <- 소유자 로그인 시에만 노출
|  +---------------------------------------------------+  |
|                                                         |
|  +---------------------------------------------------+  |
|  | [G] Google 블로그                             [X] |  | <- 타이틀 클릭 시 수정, [X]로 삭제
|  +---------------------------------------------------+  |
|                                                         |
|  +---------------------------------------------------+  |
|  | [O] Github 저장소                             [X] |  | <- 좌측 아이콘은 URL 기반 자동 파비콘
|  +---------------------------------------------------+  |
|                                                         |
|                                                         |
|                  [ Made with My-Link ]                  |
+---------------------------------------------------------+
```

### 1.2 화면 구성 요소 상세
- **상단 툴바**: 페이지를 다른 사람에게 공유할 수 있는 버튼 및 계정 설정/로그아웃 버튼.
- **프로필 영역**: 프로필 이미지가 없는 텍스트 기반 구조.
- **링크 아이템**: 각 항목은 URL을 기반으로 구글 API에서 가져온 파비콘이 좌측에 표시됨. 소유자에게만 우측 끝에 삭제(`X`) 버튼이 보임.

## 3. 사용자 흐름 및 화면 전환 (User Flow)
마이링크 서비스의 전체적인 흐름을 나타낸 다이어그램입니다.

```mermaid
graph TD
    A([마이링크 접속]) --> B{로그인 상태?}
    
    B -- "No (방문자)" --> C[퍼블릭 프로필 화면]
    C --> D(링크 클릭하여 외부 이동)
    
    B -- "Yes (소유자)" --> E[내 프로필 화면 (편집 활성화)]
    E --> F[텍스트 클릭] --> G(글자가 즉시 입력창 Input 으로 변환되어 수정)
    E --> H[새 링크 추가 클릭] --> I(새로운 빈 입력창 라인이 즉시 생성 및 포커스)
    E --> J[삭제 버튼 클릭] --> K(삭제 확인 팝업)
    
    I --> E
    G --> E
    K --> E
    
    L[로그인 페이지] --> M[구글 로그인]
    M --> N{최초 가입인가?}
    N -- Yes --> O[displayName 자동 추출 및 설정]
    N -- No --> E
    O --> E
```
