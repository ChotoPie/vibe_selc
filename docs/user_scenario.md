# 사용자 시나리오 (User Scenario) - 마이링크(My-Link)

## 1. 방문자(Visitor) 시나리오: 마이링크 페이지 방문 과정

- 사용자는 **크리에이터나 개발자의 다양한 포트폴리오 및 작업물 링크를 한 곳에서 확인하기 위해** 소셜 미디어 프로필 등에 공유된 마이링크 주소(`mylink.com/displayName`)를 클릭하여 접속한다.
- 사용자는 **현재 접속한 페이지가 누구의 프로필인지 식별하기 위해** 화면 상단에 노출된 사용자 이름(`username`)과 짧은 소개글(Bio)을 확인한다.
- 사용자는 **원하는 콘텐츠(예: 유튜브 영상, 깃허브 저장소 등)로 이동하기 위해** 나열된 버튼들 중 파비콘(Favicon) 아이콘과 타이틀을 확인하고 원하는 링크를 클릭한다.
- 사용자는 **모바일 환경에서도 편안하게 콘텐츠를 탐색하기 위해** 모바일 최적화된(반응형) UI를 통해 스크롤하며 링크 목록을 둘러본다.

---

## 2. 소유자(Owner) 시나리오: 링크 추가/수정/삭제 과정

### 2.1 링크 추가 과정
- 사용자는 **새로운 포트폴리오나 콘텐츠 링크를 자신의 프로필에 등록하기 위해** 구글 로그인을 통해 관리자 페이지(또는 인라인 편집이 가능한 본인 프로필 화면)로 접속한다.
- 사용자는 **새로운 링크 항목을 생성하기 위해** 화면에 있는 '새 링크 추가' 버튼을 클릭한다.
- 사용자는 **방문자에게 링크 목적을 명확히 안내하기 위해** 해당 링크의 타이틀(제목)과 실제 접속할 URL 주소를 입력하고 저장한다.
- 사용자는 **등록된 링크가 정상적으로 표시되는지 확인하기 위해** 구글 Favicon API를 통해 자동으로 추출된 아이콘이 버튼 좌측에 나타나는 것을 확인한다.

### 2.2 링크 및 프로필 수정 과정 (인라인 편집)
- 사용자는 **기존에 등록한 링크의 오타를 수정하거나 목적지 주소를 변경하기 위해** 링크 목록에서 해당 타이틀이나 URL 텍스트를 직접 클릭하여 인라인 편집(Inline Edit) 상태로 만들고 수정한다.
- 사용자는 **자신의 직군이 바뀌거나 소개글을 최신화하기 위해** 화면 상단의 프로필 영역(사용자 이름 `username` 및 소개글)을 클릭하여 별도의 폼 이동 없이 즉시 텍스트를 수정한다.

### 2.3 링크 삭제 과정
- 사용자는 **더 이상 유효하지 않거나 노출하고 싶지 않은 링크를 제거하기 위해** 해당 링크 항목 옆에 있는 '삭제(또는 휴지통 아이콘)' 버튼을 클릭한다.
- 사용자는 **실수로 중요한 링크를 지우는 것을 방지하기 위해** "정말 삭제하시겠습니까?"라는 확인 팝업(또는 알림)에서 '확인'을 선택하여 영구적으로 삭제한다.
